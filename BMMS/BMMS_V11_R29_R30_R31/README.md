建议先提交 R29，再 R31，最后 R30；每个候选都看全部 15 点。按 `R25 → 候选 → 候选 → R25` 交替比较，优先判断变化是否超出相邻对照的波动。有可重复收益且其他点无可重复退化后，再组合胜出的策略。不要用平台“最优用时”列作为本轮对照，也不要按一次全表普降认定提速。

本地检查通过：R25 与候选集合各 216 次实际源码模型执行（各 108 次反序调度复核），FP16/BF16、四种转置均覆盖，输出逐位一致；80,598 次实际主机分派比较通过，74,002 次非目标完整启动记录不变。三个设备源码故障和一个扩大分派范围的故障被检出。Case5 元数据保护检查 384 次，Split-K 保护检查 702 次。
